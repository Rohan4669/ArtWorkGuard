# Engine evaluation (generated PDF pairs)

Fixtures are generated by `engine/tests/generate_fixtures.py` (ReportLab). Run the evaluation with
`npm run engine:eval -w backend`. The expected outcomes were written by the same author as the engine, so this shows the
approach works on *known* differences; it is not a substitute for testing on real customer artwork.

| Case | Py-PDF-Compare 2026.8.24 (evaluation only, not shipped) | Native engine (PDF.js + pdfium + OpenCV) |
|---|---|---|
| identical | identical, no report | no differences detected (report still produced) |
| changed product name / number / date | detected | detected with exact words and boxes |
| missing warning sentence | misaligned as page removed + page added (23 words added / 34 removed) | one changed page, 11 words deleted |
| added text | detected | detected |
| graphic colour change | **reported identical** | detected |
| graphic moved | **reported identical** | detected |
| graphic removed | **reported identical** | detected |
| ~3% tint shift | **reported identical** | missed at `standard`, flagged "subtle" at `high` |
| added / removed page | detected | detected |
| scanned (no text layer) | warns, returns report | warns; pixel diff finds the changed number |

## Trade-offs

| | Py-PDF-Compare | Native engine |
|---|---|---|
| Licence | contradictory (MIT vs GPL-3.0) + AGPL PyMuPDF | permissive, with the review items in LICENCES.md |
| Graphics / colour changes | not detected | detected (pixel level) |
| Text changes | detected; word counts | detected; exact words + positions |
| Page alignment | fixed lookahead (3 pages); can mis-pair edited pages | global alignment by content similarity |
| Runtimes | Python only | Node (PDF.js) + Python (pdfium/OpenCV worker) |
| Code to maintain | almost none | ~530 lines (alignment, diff, worker, thresholds) |
| Known untested areas | | false-positive rate on photographic artwork, rotated pages, non-Latin/outlined text, very large PDFs, anti-aliasing differences between renderers |

Measured speed on the 2-page A5 fixtures: ~200–300 ms per comparison, including the Python worker start-up.
